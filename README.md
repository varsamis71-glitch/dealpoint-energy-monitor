# Deal Point — καθημερινή παρακολούθηση παρόχων

Πρώτη λειτουργική βάση για προγραμματισμένη συλλογή επίσημων ιστοσελίδων.
**Η κάλυψη των 8 παρόχων δεν έχει πιστοποιηθεί. Ελέγξτε τις εκτελέσεις στη σελίδα Actions.**
Οι δοκιμές της λογικής γίνονται τοπικά. Η απευθείας πρόσβαση σε ιστοσελίδα παρόχου
από το περιβάλλον ανάπτυξης επέστρεψε HTTP 403. Χρειάζεται πρώτη πραγματική εκτέλεση
στον online λογαριασμό και προσαρμογή ανά πάροχο πριν χρησιμοποιηθεί στις πωλήσεις.

## Online ενεργοποίηση (μία φορά)

1. Δημιουργήστε ένα ιδιωτικό GitHub repository.
2. Ανεβάστε **τα περιεχόμενα** αυτού του φακέλου στη ρίζα του repository, μαζί με
   τον φάκελο `.github/workflows`. Από το μενού Add file → Upload files μπορεί να
   χρειαστεί χωριστή δημιουργία του `.github/workflows/daily.yml` μέσω Create new file.
3. Επιτρέψτε τα GitHub Actions. Το workflow ζητά δικαίωμα εγγραφής μόνο για
   να διατηρεί την προηγούμενη κατάσταση στον ειδικό κλάδο `monitor-data`.
4. Actions → Daily energy monitor → Run workflow.
5. Μετά το τέλος, κατεβάστε το `energy-report-…` από τα Artifacts της εκτέλεσης.
6. Ελέγξτε πρώτα το `health.json`, έπειτα το `programs.csv` και τις επίσημες πηγές.

Το πρόγραμμα ζητά καθημερινή εκτέλεση στις **08:37 ώρα Ελλάδας**. Η πλατφόρμα μπορεί
να καθυστερήσει ή να παραλείψει προγραμματισμένη εκτέλεση. Το workflow πρέπει να
βρίσκεται στον προεπιλεγμένο κλάδο. Οι περιορισμοί/χρεώσεις εξαρτώνται από το πλάνο
GitHub και τη χρήση Actions· ελέγξτε τα όρια του λογαριασμού σας. Τα αποτελέσματα
διατηρούνται ως artifacts για έως 90 ημέρες, με βάση και την πολιτική λογαριασμού.
Η πρώτη καταγραφή είναι baseline και δεν αποδεικνύει ότι ένα πρόγραμμα είναι νέο.

## Αρχεία ανά εκτέλεση

- `programs.csv`: ανοίγει στο Excel, ελληνικά UTF-8, διαχωριστικό `;`.
- `changes.csv`: πρώτη καταγραφή ή αλλαγή κειμένου μιας σελίδας.
- `programs.json`: τα ίδια στοιχεία για μελλοντική σύνδεση με portal.
- `report.html`: αναγνώσιμη αναφορά που ανοίγει στον browser.
- `health.json`: αποτυχίες, αριθμός σελίδων και όρια σάρωσης ανά πάροχο.
- `sources/*/latest.txt`: κείμενο πηγής όπως ανακτήθηκε σε αυτή την εκτέλεση.
- `state.json`: αποτυπώματα τελευταίων επιτυχημένων ανακτήσεων.

## Τι συλλέγει και τι χρειάζεται περαιτέρω δουλειά

Ανακαλύπτει σχετικούς συνδέσμους από τις αρχικές πηγές των ΔΕΗ, Ζενίθ, Protergia,
Φυσικό Αέριο, nrg, Enerwave, ΗΡΩΝ και Volton. Χρησιμοποιεί Chromium ώστε να
διαβάζει και JavaScript σελίδες. Κρατά τίτλο, πηγή, σχετικά αποσπάσματα χρεώσεων,
διάρκειας και προσφορών, καθώς και συνδέσμους PDF.

**Τα αποτελέσματα είναι υποψήφιες σελίδες προγραμμάτων και ενδέχεται να περιλαμβάνουν
κατηγορίες ή παλαιότερα προϊόντα.** Δεν εξάγει μία «τελική τιμή kWh», δεν ταξινομεί
αυτόματα οικιακό/επαγγελματικό ή σταθερό/κυμαινόμενο και δεν επιβεβαιώνει ημερομηνία
ισχύος. Αυτό αποφεύγει την ανάμειξη τιμών ημέρας/νύχτας, κλιμάκων, εκπτώσεων,
ιστορικών μηνών ή διαφορετικών μονάδων. Χρειάζονται ειδικοί κανόνες ανά πάροχο
και επαλήθευση σε τρέχοντα δείγματα για αξιόπιστο συγκριτικό τιμοκατάλογο.

Τα PDF παρατίθενται ως σύνδεσμοι χωρίς ανάλυση περιεχομένου. Δεν παρακάμπτει
robots.txt, CAPTCHA, HTTP 403 ή login. Αν αποτύχει μια πηγή, εμφανίζει αποτυχία
και διατηρεί μόνο το προηγούμενο αποτύπωμά της. **Δεν εμφανίζει παλιά δεδομένα ως
σημερινά και δεν χαρακτηρίζει ένα πρόγραμμα καταργημένο λόγω αποτυχίας.**
Αλλαγή κειμένου δεν αποδεικνύει αλλαγή τιμής. Σελίδες με πολλαπλά προγράμματα
χρειάζονται ανθρώπινο έλεγχο. Όριο 45 HTML σελίδων ανά πάροχο, μόνο στον
συγκεκριμένο host. Η εξάντληση ορίου επισημαίνεται ως μερικός έλεγχος.

## Τοπικός έλεγχος

```bash
python -m unittest -v
pip install -r requirements.txt
python -m playwright install chromium
python monitor.py
```

Η ενεργοποίηση στον online λογαριασμό και η επαλήθευση πραγματικών αποτελεσμάτων
είναι χωριστά βήματα από την παράδοση του κώδικα. Δεν απαιτείται OpenAI API key.
